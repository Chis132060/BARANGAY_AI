## 6 Primary Data Fields (Record Table)

| # | Field Name |
|---|------------|
| 1 | Resident ID |
| 2 | Resident Full Name |
| 3 | Document Type Requested |
| 4 | Request Status |
| 5 | Date Filed |
| 6 | Action |

---

## 3 Key Performance Indicators (KPIs)

1. **Total Document Requests** — Total number of barangay document requests submitted by residents.
2. **Pending Approvals** — Number of requests currently awaiting review or approval by barangay staff.
3. **Registered Residents** — Total number of verified residents registered in the system.
